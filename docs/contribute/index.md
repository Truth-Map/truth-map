# Contribute to Truth Map

Anyone can help.  
Nothing enters the official record until it is reviewed under the project rules.

You can stay completely anonymous forever, or request public recognition if you want to feel part of the effort.

---

## Quick tip form (zero identity)

Use the **[Tip form](../interactive-contribute.html)** to draft a submission package.  
It never asks for a name or account. You copy the package into a GitHub Issue (GitHub still requires an account to post; the issue text itself can stay anonymous).

---

## Restricted Grok Session (recommended for deeper work)

Outside researchers can work with Grok under the same standards as the core project. Every output is a **proposal only**.

### How to start a session

1. Open a **new** Grok chat at [grok.x.ai](https://grok.x.ai) or on X.
2. Paste this starter:

```
Read and fully adopt the instructions at:
https://truth-map.github.io/truth-map/contribute/session

Confirm you have loaded the current Truth Map Contributor rules and are now operating under them. Then wait for my first request.
```

3. Wait for Grok to confirm the rules.
4. Make your request (propose a card, check sources, dig for primary documents, etc.).
5. When ready, ask Grok to prepare a submission package and paste it into a GitHub Issue.

→ [Contributor Session Instructions](session.md)

## Other ways to contribute

- Open a GitHub Issue: [New Issue](https://github.com/Truth-Map/truth-map/issues/new)
- Use titles like `New Evidence: …`, `Correction: …`, `New Claim proposal: …`
- Point out labeling errors or missing counter-evidence

---

## Anonymous vs Named

**Anonymous is fully supported.**  
**Optional recognition:** ask to be listed on the Contributors page under any handle you choose. No real identity required.

---

## Core rules (never change)

1. Primary sources first  
2. Five-term labels: True / Likely but Unproven / Contested / Highly Unlikely / False  
3. Always show evidence for *and* against when relevant  
4. Keep language simple  
5. No doxxing or illegal material  
6. Public can suggest; gatekeeper reviews before anything becomes official  
7. Association ≠ participation, knowledge, or control
